# 腦工 (Brainfactory) Design Spec v1.0

凍結日期：2026-10-14
目的：任何 agent（Codex / Claude Code / 其他）在動 Brainfactory 的 UI 之前，必須先讀完這份文件；改完之後逐條對照檢查。不經 Ken 同意，不得改動本文件。

---

## 0. 設計原則（最高指導，衝突時以此為準）

1. **現場優先**：工人戴手套、站著操作、光線差 → 大按鈕、大字、高對比，不准小字小按鈕。
2. **掃碼即動作**：scan = action。掃完即完成寫入，不再多一步確認。
3. **三畫面原則**：工人端只有 3 個畫面（登入 → 我的工單 → 工單動作），不准加第四個。
4. **兩端徹底分開**：工人端（現場）與管理端（辦公室）是兩個世界，不同 layout、不同資訊密度，但共用同一套 tokens。

## 1. Design Tokens（全站唯一色票字階）

### 色彩（沿用現有深藍底）
| 用途 | 色值 | 備註 |
|---|---|---|
| 背景底 | `#111c36` | 現有 theme-color，沿用 |
| 卡片/表面 | `#1b2745` | |
| 次表面/hover | `#24304f` | |
| 主文字 | `#f8fafc` | |
| 次文字 | `#94a3b8` | 輔助說明、時間戳 |
| 主動作（primary） | `#2f7cf6` | 按鈕、進行中狀態 |
| 成功 | `#22c55e` | 掃碼成功、合格、完工 |
| 警告 | `#f59e0b` | 待確認、異常待處理 |
| 危險/錯誤 | `#ef4444` | 掃錯件、NG、失敗，全屏使用 |
| 分隔線 | `#2a3a5f` | |

### 字體
- 全站 `Noto Sans`（已在用，不准換）。
- 工人端最小字級 **18px**；管理端最小 14px。

| 用途 | 字級/字重 | 使用處 |
|---|---|---|
| 巨字（掃碼提示、數量） | 32px / 700 | 工人端 |
| 大字（按鈕文字、工單號） | 20px / 700 | 工人端 |
| 標題 | 20px / 700 | 管理端 |
| 內文 | 16px / 400 | 兩端 |
| 輔助 | 14px / 400 | 只限管理端 |

### 圓角與間距
- 按鈕圓角 12px；卡片圓角 8px；深色底下陰影最小化（能不用就不用）。
- 間距採 8pt grid（8 / 16 / 24 / 32）。

## 2. 工人端（現場終端）—— 三個畫面，多一個都不准

裝置假設：10 吋平板橫放為主，手機直放兼顧。觸控目標最小 **64px 高**（戴手套）。

### 畫面 1：登入
- 全屏置中：「請掃描員工證」巨字＋大掃碼圖示。
- 下方小字連結：「沒帶證？用 PIN 登入」→ 切換為大數字鍵盤（PinPad 元件），輸入 4 碼。
- 登入成功直接進畫面 2，不准經過任何 dashboard。

### 畫面 2：我的工單
- 只顯示「登入者工作站＋班別」過濾後的工單，不顯示全廠。
- 每筆一張大卡片，內容只放四項：工單號、品號、數量、交期（大字）。
- 預設反白第一筆（通常就是現在要做的）。
- 選定方式：點卡片，或掃工單 label 條碼（兩者等價）。

### 畫面 3：工單動作
- 頂部固定狀態列：人名、工單號、時間；右上角小字「登出」。
- 畫面只放該工單的動作大按鈕，全寬排列：**開工 / 報工 / 報 NG / 完工**。
- 掃工件條碼 = 報工（scan 即寫入，不再問一次）。
- 閒置 10 分鐘自動登出；換人時掃自己的員工證直接切換，不用先登出。

### 工人端回饋規範
- 成功：綠色全屏閃（0.5 秒）＋大字「已報工」。
- 失敗：紅色全屏＋大字原因（例如「掃錯件：品號不符」），不准只用小 toast。
- **工人端禁止**：dashboard、圖表、側邊選單、下拉選單（選項一律用大按鈕列表）、分頁籤超過 3 個。

---

## 3. 管理端（辦公室）

- 允許高資訊密度：表格、篩選列、圖表、批次操作都可以。
- 但元件必須來自第 4 節清單，不准自創樣式。
- 語言：繁中（zh-Hant）為主。

---

## 4. 元件清單（唯一可用，新增需更新本文件）

| 元件 | 規格 |
|---|---|
| Button | 三尺寸：`lg`（工人端專用，高 64px、字 20px）、`md`、`sm`（管理端）；三語義：primary / success / danger |
| Card | 工單卡片、資訊卡，圓角 8px，背景 `#1b2745` |
| StatusPill | 狀態徽章：待開工（藍）/ 進行中（藍）/ 待品檢（黃）/ 完工（綠）/ NG（紅） |
| BigInput | 工人端輸入框，高 64px、字 20px |
| PinPad | 大數字鍵盤，只用於 PIN 登入 |
| ScanPrompt | 「等待掃描」全屏提示元件（含圖示＋巨字） |
| Table / FilterBar | 管理端專用 |
| Modal | 兩端共用，工人端 Modal 按鈕必須是 `lg` |
| EmptyState | 無資料時的圖＋字（兩端共用文案語氣） |
| ErrorBanner | 頂部錯誤橫幅，紅底 |

---

## 5. 掃碼互動規範（銜接 barcode 評估）

- 掃碼等待狀態必須常駐可見（相機掃碼框，或「等待掃描槍輸入」提示）。
- 同一工單＋序號 10 分鐘內重掃 → 提示「已掃過」，不重複寫入。
- 掃碼時比對當前工單品號，不符 → 紅色全屏「掃錯件」，拒絕寫入。
- 條碼下方一律印人類可讀編號；掃不到時允許手動輸入＋標記「手動」。

---

## 6. Agent 施工規範（防發散，Codex / Claude Code 通用）

1. 改 UI 前讀本文件，改完逐條對照；對不上的改動不准送。
2. 一次只改小 diff，不准重寫整個檔案。
3. 不准引入新顏色、字體、元件庫 —— 需要的話先更新本文件並經 Ken 同意。
4. 工人端不准加 dashboard、圖表、選單、第四個畫面。
5. 每次 UI 改動附截圖（或逐項文字描述畫面差異）。
6. RWD 順序：先平板橫放，再兼顧手機直放；桌面版只求管理端可用。

## 8. 語言（v1.1 新增）

- 工人端：繁中（zh-Hant）＋ 越南文（vi）並列，依使用者 `language` 欄位切換，預設跟著使用者設定。
- 管理端：繁中為主。
- 翻譯字典集中在 `packages/shared/src/i18n.ts`，全系統唯一來源；新增文案必須中越同步，缺翻譯不准上線。
- 越南文 v1 翻譯需母語者校對（試用前）。
